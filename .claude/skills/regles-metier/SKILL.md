# Règles métier de Dramatoons

Ne lire que le fichier correspondant au sujet de la tâche :

| Sujet | Fichier |
| --- | --- |
| Webtoons : création, visibilité (bibliothèque, catalogue, recherche, administration), publication, modification/suppression, suivis | [webtoons.md](webtoons.md) |
| Utilisateurs : comptes, rôles, gestion des utilisateurs | [utilisateurs.md](utilisateurs.md) |
| Extension navigateur | [extension.md](extension.md) |

Ces règles décrivent le comportement attendu, pas forcément celui du code actuel. En cas d'écart entre une règle et le code, le signaler à l'utilisateur plutôt que de supposer que l'un ou l'autre a raison.
